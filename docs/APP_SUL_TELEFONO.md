# Usare l'app dal telefono

L'app è fatta anche per il telefono (si adatta allo schermo) e si può aggiungere alla schermata Home
come un'app. Per farlo serve un indirizzo web (https).

## Con il sito su GitHub (quando l'account torna attivo)

Aprire https://antoniodenuccio1995-a11y.github.io/Trading-sport/ dal telefono, poi:
- iPhone (Safari): Condividi → "Aggiungi alla schermata Home";
- Android (Chrome): menu ⋮ → "Installa app" o "Aggiungi a schermata Home".

## Nel frattempo: un indirizzo alternativo gratuito

`sito-pronto.zip` contiene il sito già compilato (le stesse pagine che GitHub pubblica).
Si può caricare su un servizio gratuito di siti statici, ad esempio Cloudflare Pages
("Workers e Pages" → crea → Pages → carica i file) o Netlify ("Deploy manually", trascinando la cartella).
Serve un account gratuito sul servizio; l'indirizzo che si ottiene funziona su computer e telefono.
I dati restano su Supabase: accesso, registro trade e aggiornamenti sono gli stessi in tutti gli indirizzi.

## Senza indirizzo web

`TradingAnalytics.html` si apre con doppio clic sul computer. Sul telefono un file HTML scaricato
spesso non viene eseguito (iPhone lo mostra solo in anteprima); su Android a volte funziona aprendolo con Chrome.
